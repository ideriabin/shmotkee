Как быстро разобрать
150 фоток?

Вкладка Гардероб — операционная для шмоток. После того, как фотки залиты пачкой, нужно за один сеанс разнести их по слотам: верх / низ / платья / верхняя / обувь / аксессуары / другое.

Ниже четыре подхода для тач-устройств (iPhone/iPad), плюс один «идеальный» как ориентир. Каждый показан в виде последовательных экранов, как это будет ощущаться в реальности.

шаг 3 · финиш

как работает

  • После загрузки сразу открывается фуллскрин-триаж, один айтем на экран.
  • Большой превью сверху, сетка из 8 кнопок снизу (7 слотов + «Позже»).
  • Один тап → айтем уезжает, следующий въезжает.
  • Свайп влево вверху = «назад» — переклассифицировать предыдущий.

Сильные стороны

  • 0 ментальной нагрузки на айтем
  • Огромные таргеты — палец не промажет
  • Можно делать одной рукой
  • Прогресс виден — «1/150»

Слабые стороны

  • Линейно — нельзя пропускать в произвольном порядке
  • Не видно контекста других вещей
  • Похожие айтемы подряд = монотонно
  • Не подходит, если шмотки одна на другую похожи

шаг 3 · тап «→ Верх», отмена 5с

как работает

  • Долгий тап на тайл или кнопка «Выбрать» включает режим выбора.
  • Тапы по тайлам добавляют/убирают из выбора.
  • Чипы сверху меняют роль: были фильтры → стали «→ В Верх», «→ В Низ».
  • Тап чипа-цели → все выбранные айтемы переезжают, появляется тост-отмена.
  • 5-секундная отмена возвращает всё назад.

Сильные стороны

  • Видишь весь гардероб параллельно
  • Группируешь похожее → разом
  • Чипы уже на экране — не надо учить
  • Отмена встроена

Слабые стороны

  • Два шага: выделить → нажать чип
  • На большом массиве — много тапов выделения
  • Чипы-цели могут крошечно отображаться
  • Долгий тап надо «обнаружить»

шаг 3 · готово, следующий

как работает

  • Тап на «без слота» айтем поднимает шторку со слотами.
  • Тап слота в шторке → айтем уезжает, шторка закрывается.
  • Никакого режима — обычный гардеробный экран остаётся.
  • Тап на уже-классифицированный айтем → знакомый item-detail.

Сильные стороны

  • Никакого переключения режимов
  • Понятно с первого тапа
  • Хорошо для трикл-импортов (1-5 шмоток)

Слабые стороны

  • 150 шмоток = 150 тапов + 150 раз ждать анимацию шторки
  • Нет батч-операций вообще
  • Утомительно при объёме

шаг 3 · подсветка цели

как работает

  • Долгий тап на айтем разворачивает веер из 7 слотов вокруг пальца.
  • Не отрывая палец, тянешь к нужному слоту — он подсвечивается.

  • Тап-без-долгого открывает item-detail (как раньше).

Сильные стороны

  • 1 жест = 1 решение, очень быстро
  • Палец не закрывает превью
  • «Мышечная память» в каждом направлении
  • Ощущается как нативная iOS-фишка

Слабые стороны

  • Учиться надо — не очевидно с первого раза
  • 7 целей на маленьком экране — теснота
  • Случайные срабатывания при скролле
  • Сложнее реализовать корректно

шаг 3 · готово за 2 тапа

как работает

моя рекомендация

02 + 01 как fallback.

Базовое поведение — множественный выбор + чипы-цели (02): она быстро группирует похожее («все футболки», «все джинсы») и батчами переносит. Это даёт максимальную скорость на 150 айтемах, потому что в гардеробе много «семей» похожих вещей.

На случай, если эта механика не зайдёт или для «остатков», в углу есть кнопка «Разобрать по одному» — она открывает поштучный триаж (01). Так у неё есть выбор: батч-режим для оптимизации, линейный режим — когда лень думать.

03 я бы оставил для трикл-импортов (когда она доливает 1-2 шмотки) — просто как поведение тапа на «без слота» айтем. 04 — слишком хитрая для v1. 05 — отличная цель для v2, когда у нас будут реальные данные для проверки модели.
